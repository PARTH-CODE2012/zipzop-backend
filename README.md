# ZipZop ad, first cut

**[zipzop-ad-9x16.mp4](zipzop-ad-9x16.mp4)**: 52 seconds, vertical 9:16 (1080×1920), H.264 + AAC, with music. To watch it, open the file and click **View raw**.

This branch only holds the video. It shares no history with the code, so nothing here ever reaches `dev` or `main`. Delete the branch once the ad is final.

## What's in it

| Time | Scene |

| 4–8 s | Logo: the wordmark inside the app's neon frame, then the tagline |

Everything on screen is the real app, run locally: a real upload, captions from the real Whisper job, the real colour grade, and the real exported file.

- **Footage:** free Pexels clips. The voice used to drive the captions is text-to-speech, and it is not audible in the ad.
- **Music:** composed for this cut. It can be swapped for a trending sound on the platform.
- **Call to action:** "Start free", with no URL yet.
- **"Up to 4K":** true on the Business plan only.
