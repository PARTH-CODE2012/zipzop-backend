UI directions — series 1

Five directions for the ZipZop visual charter, all working under the same constraint: black background, neon yellow accents, a gaming feel, and one dedicated button per feature. The same screen — the editor, milestone M3 — is restyled every time, so the comparison is about the style and not the content. Series 2, the modern set, sits in ui-directions-modern/.

1 · Arcade

Arcade cabinet, CRT, scanlines. A rack of square tiles, no rounded corners, selected clip in solid yellow.

Chakra Petch + Share Tech Mono · 0 ms motion

2 · Cockpit

Tactical HUD. Yellow carries data only. Corner brackets, background grid, telemetry strip.

Rajdhani + JetBrains Mono · 120 ms sweeps

3 · Dock

Living-room console. The tools are a centred hotbar with keys 1 to 9. Solid yellow pills, black text.

Space Grotesk + DM Mono · spring on press

4 · Terminal

Brutalist, keyboard first. Monospace throughout, yellow as a highlighter, shortcuts on screen, vim-style status line.

JetBrains Mono alone · no animation

5 · Velocity

Motorsport. Bevelled geometry, italics, tool rail on the right, dashboard gauges, hazard stripes.

Archivo + Barlow Semi Condensed · 220 ms with overshoot

What every mockup has to prove

The four states that frontend/src/styles/globals.css expects are visible in each one: clip at rest, clip selected, clip being dragged, muted track. None of them relies on hue alone.
