UI directions — series 2, modern

The brief taken further: more modern, more sellable, in the Canva spirit — rounded corners, translucency, animation — while staying a tool a professional editor can work in. The timeline is the one element kept deliberately technical: grid, ticks, monospace timecodes. Black background and neon yellow unchanged. Series 1 is one level up.

Three rules that outlive the choice of direction

  • Blur and translucency stop at the chrome. No timeline clip carries a backdrop-filter or a permanent halo: the timeline has to stay smooth at 500 clips.
  • Neon yellow is never body text. It carries an active state, a data value, or a fill — never a paragraph.
  • No state relies on hue alone: a muted track dims and swaps its icon, a dragged clip changes both border and position.
